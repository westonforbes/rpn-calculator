# RPN Calculator

A browser-based Reverse Polish Notation calculator that installs as an app and works offline. Yeah, thats pretty much it.

## Accessing Calculator
This calculator is hosted at:
https://westonforbes.github.io/rpn-calculator/

## Installing on Phone
- Chrome/Edge on Android - Click the install button that appears at the bottom of the screen.
- Firefox - Does not offer install option.
- Safari - Follow instructions once you click the install button.

## Updating
Note to myself about updating: Change the version at the top of `sw.js` so installed copies pick up the new version.
